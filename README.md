# Expense Calculator (Go)

Простой калькулятор расходов на Go. Пользователь вводит суммы трат, программа считает общую сумму, количество покупок и средний чек.

## Возможности

- Суммирование всех введённых чисел.
- Подсчет количества покупок (счётчик транзакций).
- Расчёт среднего чека.
- Защита от отрицательных значений.
- Обработка случая "У вас не было трат."(Защита от деления на ноль).

## Как запустить

1. Убедись, что установлен Go.
2. В терминале в папке проекта выполни команду:
  ```bash
  go run main.go
  ```
3. Вводи суммы расходов. Чтобы завершить работу, введи 0.

## Пример работы

```text

Калькулятор расходов (вводите числа, чтобы завершить работу введите - 0).
Сколько вы потратили? 500
Сколько вы потратили? 123.95
Сколько вы потратили? -45
Число не может быть отрицательным,введите корректное число.
Сколько вы потратили? 0

Всего вы потратили: 623.95.
Всего транзакций совершено: 2.
Ваш средний чек: 311.98.
```
